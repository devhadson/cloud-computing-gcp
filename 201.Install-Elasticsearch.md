# Descargar e instalar Elasticsearch en GCP

Conjunto de comandos se utiliza para **descargar e instalar Elasticsearch (versión 8.x)* en un sistema operativo basado en Debian o Ubuntu, utilizando su repositorio oficial de forma segura.

## Pre - requisitos:

- APIs activadas: Compute Engine API.
- MV habilitada:  MV creada en GCP.

Aquí tienes el desglose paso a paso de lo que hace cada línea:

## 1. Instalar Wget

```bash
 sudo apt-get install wget
 ```

- **Qué hace:** Instala la herramienta wget, que sirve para descargar archivos desde internet a través de la terminal.

## 2. Descargar y registrar la clave de seguridad (GPG)

```bash
wget -qO - https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo gpg --dearmor -o /usr/share/keyrings/elasticsearch-keyring.gpg
```

- **Qué hace:** Descarga la clave criptográfica oficial de Elastic y la guarda en un formato que el sistema entiende (`.gpg`).
- **Para qué sirve:** Garantiza que el software que vas a descargar es original, no ha sido alterado y proviene realmente de Elastic.

## 3. Habilitar soporte para repositorios HTTPS

```bash
sudo apt-get install apt-transport-https
```

- **Qué hace:** Asegura que el gestor de paquetes (`apt`) pueda comunicarse y descargar programas de forma segura a través de enlaces cifrados `https://`.


## 4. Agregar el repositorio oficial de Elastic

```bash
echo "deb [signed-by=/usr/share/keyrings/elasticsearch-keyring.gpg] https://artifacts.elastic.co/packages/8.x/apt stable main" | sudo tee /etc/apt/sources.list.d/elastic-8.x.list
```

- **Qué hace:** Añade la dirección del servidor de descargas de Elastic (específicamente la rama **8.x**) a la lista de fuentes de tu sistema y la vincula con la clave de seguridad del paso 2.


## 5. Actualizar la lista e instalar el programa

```bash
sudo apt-get update && sudo apt-get install elasticsearch
```

- **sudo apt-get update:** Hace que tu sistema lea las nuevas direcciones que acabas de agregar para saber qué versiones hay disponibles.
- **sudo apt-get install elasticsearch:** Descarga e instala el motor de búsqueda Elasticsearch en tu máquina.

## 6. Recargar y activar el servicio en el sistema

```bash
sudo /bin/systemctl daemon-reload
sudo /bin/systemctl enable elasticsearch.service
```

- **daemon-reload:** Avisa al sistema operativo que hay un nuevo servicio de fondo (en este caso, Elasticsearch) disponible para ser administrado.
- **enable:** Configura Elasticsearch para que se **inicie automáticamente** cada vez que enciendas o reinicies el servidor.

> [!NOTA]
> Después de ejecutar estas líneas, el programa estará listo e instalado, pero apagado, para encenderlo por primera vez deberás ejecutar _sudo systemctl start elasticsearch_).
