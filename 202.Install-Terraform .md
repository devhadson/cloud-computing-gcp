# Instalación de Terraform

Existen tres formas sencillas de realizar este proceso, desde la instalación manual tradicional hasta el administrador de paquetes nativo.


## Método 1: Instalación Manual (Tradicional)
Si prefieres controlar de forma exacta en qué carpeta se aloja el ejecutable, sigue estos pasos:

### 1. Descargar el binario

* Entra al [sitio oficial de descargas de Terraform](https://developer.hashicorp.com/terraform/install).
* Busca la sección de Windows y descarga el archivo ZIP correspondiente a tu arquitectura (habitualmente AMD64 o x64).

### 2. Organizar el archivo

* Crea una carpeta dedicada en tu almacenamiento principal, por ejemplo: `C:\Terraform`.
* Extrae el contenido del archivo ZIP descargado (encontrará únicamente un archivo llamado terraform.exe) dentro de la carpeta que acabas de crear. 

### 3. Configurar la Variable de Entorno (PATH)
Para poder ejecutar el comando desde cualquier ubicación de la consola, debes indicarle a Windows dónde encontrarlo:

1. Presiona la tecla Windows, escribe Variables de entorno o `env' y selecciona Editar las variables de entorno del sistema.
2. Haz clic en el botón Variables de entorno... en la parte inferior.
3. En la sección Variables del sistema, busca la variable llamada Path y haz doble clic sobre ella.
4. Haz clic en el botón Nuevo a la derecha y pega la ruta exacta de tu carpeta: `C:\Terraform`.
5. Haz clic en Aceptar en las tres ventanas abiertas para guardar los cambios. 


### Verificación de la instalación
Sin importar el método que hayas elegido, comprueba que el sistema reconoce la herramienta correctamente: 

   1. Abre una nueva ventana de PowerShell o CMD (las consolas abiertas previamente no detectarán el cambio).
   2. Ejecuta el siguiente comando para comprobar la versión instalada en bash o PowerShell:
   
Bash
```bash
   terraform -version
```
PowerShell
```PowerShell
    terraform --version
```

Si todo ha salido bien, la pantalla devolverá el número de versión activa de Terraform. 

## Método 2: Usando Winget (El más rápido y recomendado)
Windows 11 incorpora winget, su propio administrador de paquetes nativo. No necesitas descargar nada manualmente desde el navegador.

   1. Haz clic derecho en el botón de Inicio y selecciona Terminal (Administrador) o PowerShell (Administrador).
   2. Copia, pega y ejecuta el siguiente comando:

PowerShell
```PowerShell
   winget install HashiCorp.Terraform
```

   3. Reinicia la terminal para que aplique los cambios.

## Método 3: Usando Chocolatey (Si usas este gestor)
Si ya utilizas Chocolatey para administrar tus programas en Windows, el proceso requiere un único comando.

   1. Abre la terminal o PowerShell como Administrador.
   2. Ejecuta el comando de instalación:

```PowerShell   
   choco install terraform
```
   3. Reinicia la terminal activa.

> Para instalar Terraform en Windows 11 de forma rápida, abre la terminal como administrador y ejecuta el comando `winget install HashiCorp.Terraform`.
